# Pizza Ordering Web Application

A responsive **frontend web application** that simulates an end-to-end online pizza ordering experience. This project focuses on **user interface design**, **dynamic cart logic**, and **smooth multi-page navigation** without relying on a live backend database.

## 🚀 Key Features

* **Dynamic Digital Menu:** Browse various pizza options with custom layouts.
* **Interactive Shopping Cart:** Add, update, and remove items seamlessly.
* **Authentication Mockup:** Dedicated login and signup forms for users.
* **Simulated Checkout Flow:** Multi-step process from cart to final confirmation.
* **Fully Responsive Design:** Optimized for both desktop and mobile screens.

## 🛠️ Tech Stack

* **HTML5:** Structured semantic markup for all pages.
* **CSS3:** Custom styling, layouts, and interactive hover effects.
* **JavaScript (ES6):** Handles cart states and page interactions.
